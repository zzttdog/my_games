Game 02

The White Castle

姬路城 + 茶道扩 Matcha

多文件结构（assets / css / js / test / tools），含棋盘、卡牌与 AI 对局模块。

选择对战模式

玩家 vs AI单机 · 原版设置页，可选 AI 难度 玩家 vs 玩家联机 · 4 位房间号，人齐再开始
./The White Castle/index.html
玩家 vs 玩家（联机）流程：房主创建 4 位数字房间号 → 其他玩家输入房间号加入 → 房主统一设定开局规则 → 真人全部到齐后房主点「开始对局」，所有窗口才同时开局。不会自动开始。
游戏外 · 房间设置（只决定怎么连，不写进游戏状态）：游戏、房间号、昵称、联机通道。
游戏内 · 开局规则（房主冻结，所有窗口一致）：真人人数 1~4、是否添加 AI 及数量 0~3（总席位 2~4）、先手座位、版图 / 扩展、AI 难度。AI 只由房主窗口代跑，其余窗口为纯镜像；进入对局后原版设置页隐藏，两边不能再各选人数或难度。
手机 / 平板：自然和弦两个入口都自带响应式布局（CSS 按 ≤1049 / ≤899 / ≤620 / ≤420 四档切换，任何宽度都不需要左右滑动，纵向滚动即可），单机与联机共用同一套样式；联机页顶栏的 A− / A+ 仍可调字号。姬路城联机入口按桌面宽度渲染后整体缩放，可拖动查看局部；其单机入口在窄屏会自动走等比缩放外壳页 net/client/phone.html（按最小可用宽度排版后整体缩到屏幕宽），顶栏可切「原尺寸 / 适配」。
纯静态部署（GitHub Pages / git 静态页）只支持「同一浏览器、同一站点的多个窗口」联机；跨设备或跨浏览器必须运行 node net/server/server.js（当前 GitHub Pages 站点为纯静态版本，跨设备联机请另起 Node 服务）。
在 my_games/ 根目录启动 Live Server 后访问本页即可。
联机层只对 net/ 下的文件生效，两个游戏本体文件零改动。
